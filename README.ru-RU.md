Это самостоятельный проект темы, который можно передать Codex или Pi для генерации, а затем напрямую импортировать в [Pi-Harness](https://github.com/wangmiaozero/pi-harness).

## Быстрый старт

1. Используйте этот репозиторий как шаблон либо скачайте и распакуйте его.
2. Откройте каталог проекта в Codex или Pi.
3. Скопируйте запрос ниже, замените последнюю строку описанием нужной темы и отправьте его.
4. После генерации и проверки откройте в Pi-Harness **Настройки → Тема → Импортировать тему** и выберите каталог проекта.

## Готовый запрос

Используйте кнопку копирования в правом верхнем углу блока кода:

```text
Создай в текущем проекте полноценную пользовательскую тему, которую можно напрямую импортировать в Pi-Harness.

Требования:
1. Сначала полностью прочитай AGENTS.md, SKIN_BRIEF.md, skin.schema.json и pi-harness-skin.json.
2. Изменяй только текущий проект темы. Не изменяй приложение Pi-Harness и не создавай файлы за пределами этого проекта.
3. Создай следующие ресурсы:
   - assets/wallpaper.webp: фон приложения 16:9, сохраняющий читаемость текста на полупрозрачных панелях.
   - assets/portrait.webp: вертикальное изображение персонажа с прозрачным фоном и достаточными безопасными полями; его можно не создавать, если персонаж не нужен.
   - assets/preview.webp: превью карточки темы 16:10, точно отражающее конечный результат.
4. Обнови pi-harness-skin.json в соответствии с изображениями: задай уникальный id в kebab-case, название, версию, светлое/тёмное оформление, относительные пути к ресурсам и полный набор цветовых токенов.
5. Изображения должны быть в формате PNG, JPEG или WebP, каждый файл — меньше 12 MiB. Запрещены внешние URL, SVG, CSS, JavaScript, HTML, шрифты и исполняемые файлы.
6. После завершения проверь проект по skin.schema.json, убедись, что все ресурсы существуют по указанным путям, и выведи итоговый список файлов и результаты проверки.

Моя тема: императорский двор эпохи Мин под снегом, киноварно-красная, чёрная и золотая палитра, величественный и сдержанный чиновник эпохи Мин; без современной архитектуры, неона и киберпанка.
```

Достаточно заменить последнюю строку `Моя тема`. Более подробные требования к дизайну можно указать в `SKIN_BRIEF.md`.

## Ожидаемые файлы

```text
pi-harness-skin.json
assets/
├── wallpaper.webp
├── portrait.webp
└── preview.webp
```

- `wallpaper.webp`: фон приложения 16:9.
- `portrait.webp`: необязательное вертикальное изображение персонажа с прозрачным фоном.
- `preview.webp`: превью карточки выбора темы 16:10.
- `pi-harness-skin.json`: метаданные темы, пути к ресурсам и цветовые токены.

## Импорт темы

1. Запустите Pi-Harness.
2. Откройте **Настройки → Тема**.
3. Нажмите **Импортировать тему**.
4. Выберите каталог проекта, содержащий `pi-harness-skin.json`.
5. Выберите карточку новой пользовательской темы, чтобы включить её.

## Обновление темы

Не изменяйте `id` в `pi-harness-skin.json`. После обновления изображений, цветов или номера версии повторно импортируйте тот же каталог проекта. Pi-Harness безопасно заменит установленную копию.

## Пример манифеста

```json
{
  "$schema": "./skin.schema.json",
  "schemaVersion": 1,
  "id": "my-custom-skin",
  "name": "Моя пользовательская тема",
  "version": "1.0.0",
  "appearance": "dark",
  "assets": {
    "preview": "assets/preview.webp",
    "wallpaper": "assets/wallpaper.webp",
    "portrait": "assets/portrait.webp"
  },
  "tokens": {
    "window": "#111318",
    "workspace": "#1b1f27",
    "textPrimary": "#f3f5f7",
    "accent": "#6f9df4"
  }
}
```

Полные ограничения полей описаны в `skin.schema.json`. `id` может содержать только строчные латинские буквы, цифры и дефисы. Не меняйте его после публикации, иначе Pi-Harness распознает результат как другую тему.

## Безопасность и ограничения ресурсов

- Поддерживаются только файлы PNG, JPEG и WebP внутри проекта.
- Размер каждого изображения должен быть меньше 12 MiB.
- Пути к ресурсам должны быть относительными; нельзя использовать `..`, абсолютные пути или символические ссылки за пределы проекта.
- Внешние CSS, JavaScript, SVG, HTML, шрифты и сетевые URL не поддерживаются.
- Pi-Harness копирует только проверенные манифесты и растровые изображения и не выполняет код из проектов тем.
